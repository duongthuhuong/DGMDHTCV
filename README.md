# Đổi mới phương thức quản trị công việc tại PVEP

Trang thuyết trình giới thiệu mô hình đổi mới quản trị công việc theo mục tiêu tại PVEP, kết hợp giao việc, theo dõi tiến độ, đánh giá theo mức độ tạo ra giá trị và triển khai trên nền tảng số 1Office.

## Sử dụng

- Mở trang GitHub Pages để xem bài trình bày.
- Dùng phím mũi tên trái/phải để chuyển slide.
- Dùng Home/End để đến slide đầu/cuối.
- Chọn **Toàn màn hình** khi trình chiếu.
